# Nicole Nguyen portfolio

Static HTML/CSS site. Design source: Figma file "Portfolio Frontend Minimal (Community)".
The site should always match Figma, including text, images, and spacing.

## Structure
- `index.html`: home (title, subtitle, 2x2 project cards)
- `about.html`: bio, experience, leadership, awards, photo row
- `projects/`: `tiktok.html`, `glasspane.html`, `remnant.html`, `pov.html`
- `assets/`: every image
- `styles.css`: all styling

## Updating the live site
The GitHub repo is connected to Netlify, so every push to the main branch redeploys the site automatically (about a minute).
1. Edit files in VS Code.
2. Source Control > write a short message > Commit > Sync/Push.
3. Check the Netlify deploy log if something looks off.
